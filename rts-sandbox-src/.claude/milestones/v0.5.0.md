> Полное имя версии — `0.5.0-alpha`.

rts-sandbox — это движок-пакет с полигоном, а игра на нём — отдельный
проект, который ИИ создаёт, ведёт и обновляет сам. Показано на тестовой
игре «выживание волн»: правила игры живут в игре, новая механика уходит в
движок, есть инструкция для пользователя.

Подзадачи по порядку: T-072.1 (дока процесса, на утверждение) → T-072.2
(движок в пакет) → T-072.3 (создание игры) → T-072.4 (тестовая игра) →
T-072.5 (механика из игры в движок) → T-072.6 (инструкция и показ).
