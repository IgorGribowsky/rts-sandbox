> Полное имя версии — `0.4.0-alpha`.

Цвет команды лежит только на отведённых частях модели, остальное у всех
одинаковое. Любую модель ИИ сам превращает в юнита с командными частями
через Blender — по просьбе в чате.

Подзадачи по порядку: T-031.1 (захваченный рудник, первый проход
конвейера), T-031.2 (скилл на любую модель), T-031.3 (все модели проекта
через конвейер — добавлена 2026-10-05 по ответу в чате: правило строгое,
и к выходу версии цвет команды должен быть у всех). Способ разметки —
материал-слот `TeamColor` (Q-21).
