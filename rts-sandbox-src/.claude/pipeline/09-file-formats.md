То, что скрипт читает механически. Проза внутри файлов свободная, а эти
поля — нет: сломаешь формат, доска нарисует ⚠ INVALID с именем файла.
Полная схема задачи с правилами валидации — .claude/templates/task-schema.md

Общие правила front-matter: блок между --- в самом начале файла, одна пара
«ключ: значение» на строку, значения — скаляры или инлайн-списки [A, B].
Вложенности и многострочных значений нет намеренно: то, что ИИ пишет,
скрипт обязан прочитать однозначно.

  blocked-by: []             [Q-4] [H-002] [T-007] — обязательно при blocked
  mechanics: [M-002]         доки, которые задача реализует
  handoff: [H-001]           заглушки, которые она оставила
  checkpoint:                короткий хеш последнего cp(T-004)

  updated: 2026-08-11        дата смены статуса. По ней видно, что приёмка
                             висит давно, и ИИ напоминает про плейтест

  Разделы тела, порядок фиксирован: Что нужно · Как проверить · План ·
  Решения · Итог. План — рабочий чек-лист ИИ с отметками [x], он же журнал
  работы; читать его тебе не нужно. В задачах, заведённых до 0.3.0, бывает
  отдельный раздел «Ход работы» — это нормально.

  ПОДЗАДАЧИ: отдельные файлы, id суффиксом — T-012.1, T-012.2. Глубина одна,
  T-012.1.1 не бывает. В работу берётся только подзадача, родитель —
  контейнер, доска рисует его прогресс как 2/4. В список tasks версии
  подзадачи НЕ перечисляются: принадлежность наследуется от родителя.

  ЗАВИСИМОСТЕЙ между задачами нет. Порядок задаёт файл milestone, реальная
  блокировка выражается статусом blocked и полем blocked-by.

--------------------------------------------------------------------------------
  Чем это проверяется
--------------------------------------------------------------------------------

  node .claude/scripts/board.js --validate

  Ловит больше двадцати видов поломок: битый статус, дату не по формату,
  вложенность во front-matter, две задачи in-progress сразу, две текущие
  версии, blocked без blocked-by, needs-design вместе с in-progress, done
  не в tasks/done/, дубли ID, ссылки на несуществующие Q- H- T-, задачу,
  которая заявляет версию, а версия её не перечисляет, родителя done при
  незакрытых детях. Код возврата 1 при ошибках — ИИ обязан прогонять это
  после правки задач и исправлять найденное сам.
