# references/ — чужие материалы

Скрины из других игр, куски чужого кода, PDF с механикой, что угодно.
Вложенные папки — как тебе удобно, имена свободные.

## Правило, ради которого эта папка отдельная

**ИИ не открывает содержимое отсюда сам.** Перечислить имена файлов он может
свободно, а открыть — только когда ты прямо сослался: «сделай HUD как на
ui-inventory-diablo.png».

Причина не в аккуратности, а в деньгах: картинки стоят очень дорого в
контексте, и одно «посмотри, что там есть» съедает половину сессии.

## Как ссылаться

В файле идеи или прямо в чате называй имя файла:

    Референс по картинке — geometry-wars-ref.png, нужен такой же неон.

ИИ откроет именно его. Если положил что-то и не сослался — оно просто лежит,
пока не понадобится.
