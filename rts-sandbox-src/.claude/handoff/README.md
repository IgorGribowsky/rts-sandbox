# handoff/ — что игра ждёт от тебя

ИИ не умеет рисовать модели, писать музыку и заводить аккаунты в сторах.
Когда работа упирается в такое, он ставит честную заглушку — красную капсулу
вместо модели, писк вместо выстрела — и создаёт здесь файл `H-NNN`.

## Что делать тебе

1. Панель `[2] Ждёт тебя` на доске, Enter на строке `H-NNN` — откроется
   та самая папка, куда положить файл.
2. Положил файл. **Больше ничего делать не надо, говорить ИИ не надо.**
3. Доска увидит файл в целевой папке и сама переведёт кейс в `ready`.
4. Когда захочешь — в чате: «внедри готовые ассеты». ИИ возьмёт всё `ready`
   и внедрит пачкой. Ассеты сгруппированы по типу, поэтому все модели можно
   сделать за один заход.

## Статусы

    waiting      файла ещё нет
    ready        файл лежит в целевой папке, ждёт внедрения
    integrated   внедрено, кейс закрыт

## `blocking`

    blocking: no    игра работает с заглушкой. Задача проходит обычную
                    приёмку и закрывается — заглушка не повод держать
                    версию открытой
    blocking: yes   без этого нельзя двинуться (нужен аккаунт, лицензия,
                    железо). Задача уходит в blocked и не притворяется
                    сделанной
