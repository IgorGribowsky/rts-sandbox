Задача: $ARGUMENTS

1. ID не назван или такого файла нет — скажи и покажи, что есть в текущей
   версии: `node .claude/scripts/board.js --brief`.
2. Запиши выбранный ID в `.claude/state.md` (поле `задача`).
3. Дальше прочитай `.claude/commands/next.md` и выполняй его начиная с шага 3.
   Дублировать цикл в двух командах нельзя: разъедутся.

Задача из другой версии, не из текущей — можно, но скажи об этом. Задача из
уже закрытой версии — не открывай, покажи и спроси.
