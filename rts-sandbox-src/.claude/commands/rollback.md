description: Откатиться к чекпоинту
allowed-tools: Bash(git:*), Bash(node:*), Read, Edit, Write

## 1. Покажи чекпоинты — это бесплатно

    git log --oneline --grep="^cp(" -n 20

Выведи списком: хеш, задача, что было до. Плюс текущий `checkpoint` задачи
из `.claude/state.md`. Пользователь выбирает. Сам не выбирай.

## 2. Скажи, что потеряется, и дождись подтверждения

    git diff --stat <хеш>..HEAD -- . ':(exclude).claude'

Откат — единственная необратимая операция в пайплайне. Пользователь должен
увидеть список файлов ДО, а не после.

## 3. Unity открыт — сначала он

Скажи пользователю и дождись, что он это сделал:
1. выйти из Play mode;
2. сохранить сцены (Ctrl+S);
3. закрыть проект или хотя бы не трогать его во время откатa.

Иначе редактор перезапишет откаченное своим состоянием из памяти, и ты
получишь мистический баг, которого нет.

## 4. Откат

    git checkout <хеш> -- . ':(exclude).claude'

**`.claude/` из откатa исключена ВСЕГДА.** Иначе пропадёт запись о самом
откате и вернутся старые статусы задач — то есть пропадёт понимание, что
вообще произошло.

## 5. После

- Пользователь переоткрывает проект в Unity и даёт переимпортировать ассеты.
- В файл задачи, раздел `Ход работы`: что откатили, к какому хешу, почему.
- `status`: `todo`, если будем делать заново, `cancelled` — если отказались.
- `.claude/state.md` привести в соответствие.
- Коммит: `rollback T-XXX to <хеш>: <причина>`. Историю не переписываем —
  откат тоже событие проекта.
