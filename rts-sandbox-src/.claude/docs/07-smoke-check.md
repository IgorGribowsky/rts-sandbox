# Смоук-проверка

Быстрый прогон после любой заметной правки. Не автотесты — глазами, за один
запуск сцены `SampleScene`. Красная консоль на любом шаге = провал.

Собрано из кода при `/adopt` 2026-09-05, пользователем ещё не проверялось.

1. Сцена стартует, в консоли нет ошибок (лог FPS от `FPSTracker` — не ошибка).
2. Камера скроллится у всех четырёх краёв экрана и упирается в границы карты.
3. Колесо мыши меняет высоту камеры плавно, `F8` фиксирует скролл.
4. Рамкой выделяется группа своих юнитов, под ними появляются круги.
5. Двойной клик по юниту выделяет всех такого же типа рядом.
6. ПКМ по земле — группа идёт строем, не наезжая друг на друга.
7. Shift + несколько ПКМ ставит очередь: юнит проходит точки по порядку.
8. `A` + клик по земле: юнит идёт и вступает в бой с врагом по дороге.
9. Стрелок стреляет снарядом, снаряд долетает и снимает HP; полоска HP
   появляется, когда HP не полные.
10. Строитель: `B`, затем `F` — под курсором сетка, зелёная на свободном
    месте, красная на занятом. Клик ставит Farm, она достраивается за 12 с.
11. `Esc` по недостроенному зданию сносит его и возвращает 70% золота.
12. Castle выделен, `1` — производится Builder, над зданием идёт полоска.
13. Строитель по ПКМ рубит дерево и сам относит на склад; золото и дерево
    в `PlayerResources` растут.
14. `G` строителем по нейтральной шахте: шахта захватывается, рабочие по
    ПКМ встают в неё, золото капает.
15. Caster Unit: `Q`, `W`, `E` кастуются в точку курсора, мана убывает и
    восстанавливается, полоска маны реагирует.
