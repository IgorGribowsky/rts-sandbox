# Смоук-проверка

Быстрый прогон после любой заметной правки. Не автотесты — глазами, за один
запуск сцены `SampleScene`. Красная консоль на любом шаге = провал.

Собрано из кода при `/adopt` 2026-09-05, пользователем ещё не проверялось.

- [ ] Сцена стартует, в консоли нет ошибок (лог FPS от `FPSTracker` — не ошибка).
- [ ] Камера скроллится у всех четырёх краёв экрана и упирается в границы карты.
- [ ] Колесо мыши меняет высоту камеры плавно, `F8` фиксирует скролл.
- [ ] Рамкой выделяется группа своих юнитов, под ними появляются круги.
- [ ] Двойной клик по юниту выделяет всех такого же типа рядом.
- [ ] ПКМ по земле — группа идёт строем, не наезжая друг на друга.
- [ ] Shift + несколько ПКМ ставит очередь: юнит проходит точки по порядку.
- [ ] `A` + клик по земле: юнит идёт и вступает в бой с врагом по дороге.
- [ ] Стрелок стреляет снарядом, снаряд долетает и снимает HP; полоска HP
   появляется, когда HP не полные.
- [ ] Строитель: `B`, затем `F` — под курсором сетка, зелёная на свободном
      месте, красная на занятом. Клик ставит Farm, она достраивается за 12 с.
- [ ] `Esc` по недостроенному зданию сносит его и возвращает 70% золота.
- [ ] Castle выделен, `1` — производится Builder, над зданием идёт полоска.
- [ ] Строитель по ПКМ рубит дерево и сам относит на склад; золото и дерево
      в `PlayerResources` растут.
- [ ] `G` строителем по нейтральной шахте: шахта захватывается, рабочие по
      ПКМ встают в неё, золото капает.
- [ ] Caster Unit: `Q`, `W`, `E` кастуются в точку курсора, мана убывает и
      восстанавливается, полоска маны реагирует.
