# Смоук-проверка

## Регламент

Установлен пользователем 2026-09-05 (ответ в чате), уточнён 2026-10-04
(ответ в чате, переход на пайплайн 0.3.0): смоук — **памятка** для ручной
проверки, а не гейт.

- **Когда:** когда пользователь сам захочет. ИИ его не прогоняет и не
  напоминает, закрытие версии от него не зависит. После обычной задачи
  проверяется только её собственный сценарий из раздела «Как проверить»
  и чистая консоль.
- **Что попадает:** только самое важное. Норма — **1-2 пункта на крупную
  механику**. Отдельная кнопка крупной механикой не является: нажатие
  `Esc`, зум колесом, `F8` сюда не пишутся.
- **Пункт — это сквозной сценарий, а не клик.** «Построить ферму» вместо
  «сетка красная на занятом месте».
- **Размер:** держать около десяти пунктов. Растёт — значит внутрь
  попали мелочи, их надо убрать, а не увеличивать список.

## Проверка

Один запуск `SampleScene`. Красная консоль на любом шаге — повод
разобраться, прежде чем идти дальше.

- [ ] Сцена стартует, в консоли нет ошибок.
- [ ] Группа выделяется рамкой и по правому клику идёт строем, не
      сталкиваясь и не застревая в зданиях.
- [ ] Ближний и дальний бой: HP цели убывает, снаряд долетает, убитый
      юнит исчезает и пропадает из выделения.
- [ ] Автоатака: подошедший враг атакован без приказа, свои сбегаются на
      зов, после погони юниты возвращаются на место.
- [ ] Строитель ставит здание: сетка показывает свободное и занятое,
      здание достраивается и начинает работать.
- [ ] Здание производит юнита: ресурсы списываются, очередь видна над
      карточками найма, юнит выходит; отмена слота возвращает цену; при
      нехватке лимита производство встаёт и потом продолжается само.
- [ ] Шахта захватывается, рабочие встают в неё, золото растёт.
- [ ] Дерево рубится, рабочий сам носит на склад, дерево растёт.
- [ ] Кастер применяет способности: мана тратится и восстанавливается,
      кулдаун держит повторный каст.
- [ ] Интерфейс и клавиши — одно и то же: меч и `A`, щит и `H`, скилл
      кликом и клавишей дают тот же приказ и ту же подсветку кнопки; клик
      по интерфейсу не двигает юнитов и не сбрасывает выделение.
- [ ] Партия мышью: здание из меню построек, юнит из списка найма, ресурсы
      наверху меняются, клик по миникарте переносит камеру.
- [ ] Толпа рабочих на лесе: 8 рабочих на одно дерево расходятся по
      соседним, минуту рубят и носят без заторов, дерево наверху растёт.
- [ ] Группа воинов ПКМ по врагу — окружают его, все бьют; шестой рабочий
      на полную шахту получает отказ и выполняет следующий приказ из Shift.
- [ ] Бой 0.3.2: гигант по `Q` впадает в ярость — значок эффекта с
      таймером левее кольца, урон в кольце растёт; `Keypad3` — звёзды над
      оглушённым и значок стана; воины и лучники время от времени дают
      красное «N!»; юниты бьют, только развернувшись к цели.
- [ ] Туман 0.3.3: на старте открыта только база, дальше чёрное; пройденное
      юнитом остаётся серым, на миникарте то же; снять `FogOfWarEnabled`
      на `GameController` во время игры — туман пропал, поставить — вернулся.
- [ ] Туман прячет чужих: враги вне обзора не видны, не выделяются рамкой и
      кликом, их нет на миникарте; выделенный враг, ушедший в туман,
      снимается с выделения; увиденные здания остаются в сером.
- [ ] Лес закрывает обзор: юнит у рощи не видит, что за ней; вдоль опушки
      видно; срубили деревья — за ними открылось.
- [ ] Цвет команды 0.4.0: красятся только командные части модели (у
      захваченного рудника — рама из балок); модель без них цвета не меняет.
