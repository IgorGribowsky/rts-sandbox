# Конвейер моделей и цвет команды

Версия 0.4.0. Требования — от пользователя (концепт, ответы в чате
2026-10-04, Q-19). Способ предложил ИИ, пользователь утвердил: Q-21, ответ
в чате 2026-10-05 — отдельный материал-слот.

## Что нужно (требования пользователя)

- Только отведённые части модели красятся в цвет команды (M-009).
- **Модель без командных частей не красится вообще** (ответ в чате
  2026-10-04). Обычный рудник — пример такой модели.
- ИИ умеет взять **любую** модель и сделать из неё потенциального юнита
  с командными частями. Работает через Blender MCP по образцу
  `E:\Gamedev\pipelines\autorigPipeline`, скиллами в этом проекте.
- Если для разметки нужно, скилл меняет меш: разбивает на большее число
  граней, чтобы провести границу командной части.
- Пользователь только просит в чате — всё остальное делает ИИ.
- Первая проверка — захваченный рудник: сам рудник своего цвета, балки
  вокруг — цвета команды. Это тестовые модели, на них тренируемся.

## Как сделать (утверждено, Q-21, ответ в чате 2026-10-05)

**Отдельный материал-слот на командные части.** В Blender грани командной
части получают материал с условленным именем (например, `TeamColor`). В
Unity `TeamMember` красит только слоты с этим материалом, остальные не
трогает. Нет такого слота — модель не красится.

Почему так, а не маской в текстуре, как в WC3:

- работает на моделях без текстур, а заглушки в проекте именно такие;
- не требует своего шейдера — Built-in RP, стандартный материал;
- разметку видно глазом в Blender и в инспекторе Unity;
- скилл может провести границу, разрезав грани, — ровно то, что разрешено
  концептом.

Маска в текстуре станет нужна, когда появятся текстурированные модели с
тонкими узорами цвета команды. Тогда это отдельная задача.

## Что войдёт в версию

- скилл (или скиллы) «модель → юнит с цветом команды»: открыть модель в
  Blender, выделить части, при необходимости порезать меш, назначить слот,
  экспортировать, подключить в типе юнита;
- код окраски по слоту в `TeamMember`;
- модели рудника и захваченного рудника, прошедшие конвейер.

## Переход
Ответ в чате 2026-10-05: правило «нет слота `TeamColor` — не красится»
включается строго, без переходного режима. Чтобы юниты не остались без
цвета команды, в 0.4.0 через конвейер проходят все модели проекта (T-031.3).
