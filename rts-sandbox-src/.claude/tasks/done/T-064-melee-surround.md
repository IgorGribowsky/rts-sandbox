# T-064 · Ближники окружают цель, дальники не толкаются

## Что нужно
Группа в бою работает как в WC3: ближники встают вокруг цели по слотам.
Если цель выбрал игрок — бьют только её, даже когда места нет, и так
окружают. Если цель выбрана сама (`A`-клик по земле, автоатака) — без
слота берут ближайшего другого врага. Дальники встают на дистанции и не
расталкивают ближников. Подробно — M-007 и M-006, «Запланировано».

## Как проверить
1. Play. 8 Warrior, ПКМ по одному вражескому юниту — окружают его со всех
   сторон, не толпятся с одной; кто не влез, ждёт рядом и не бьёт других.
2. Те же 8 Warrior, `A`-клик по земле за группой из 3-4 врагов — каждый
   нашёл себе цель, никто не стоит без дела.
3. Смешанная группа ближних и Range Unit — дальники стреляют со своей
   дистанции и не выталкивают ближников из боя.
4. Автоатака (враг подошёл сам) — как в пункте 2.
5. Ничего не застревает и не дёргается на месте после смерти цели.

## План

- [x] Места у цели двигаются вместе с ней (смещение от цели)
- [x] Ближний бой: подход к своему месту, без места — по-старому
- [x] Автоатака выбирает врага с местом
- [x] Приоритеты обхода: ближник 40, дальник в стрельбе 60, без места 70
- [x] Проверка в Play: пп. 1, 2, 3, 5

## Решения

- 2026-10-04 решения без пользователя — Q-18 пп. 6-8: радиус поиска
  другой цели — обычный `AutoAttackDistance`, ждущий без места уступает
  бьющим, места занимаются со стороны подхода.
- Зазор у места — `MeleeAttackDistance − stoppingDistance − 0.1`, иначе
  агент тормозит за дистанцией удара и не бьёт.

## Итог

Проверено в Play:
1. 8 Warrior, ПКМ по Giant — все 8 заняли свои места (8 мест у цели),
   зазор ≤ 1.0, бьют все: урон 53/с при расчётных 8 × 9 / 1.4 = 51.
2. 8 Warrior, `A`-клик по земле за 4 врагами — распределились 3/2/2/1,
   все в дистанции удара, без дела никто.
3. Плюс 4 Range Unit тем же `A`-кликом — встали на 9.6-9.9 с приоритетом
   60, ближники остались на местах (зазоры не изменились).
5. Убил цель трёх воинов — за пару секунд все трое переключились на
   соседних врагов, стоящих и дёргающихся нет. Консоль чистая.

Пункт 4 (автоатака, враг подошёл сам) идёт тем же поиском, что `A`-клик, —
глазами на плейтесте. Как выглядит окружение — тоже глазами.
