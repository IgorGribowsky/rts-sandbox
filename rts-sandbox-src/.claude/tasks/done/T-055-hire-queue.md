# T-055 · Очередь найма на экране с отменой

## Что нужно
Над карточками найма — ряд слотов очереди выделенного здания: первый с
круговым прогрессом производства, за ним ожидающие, у каждого 3D-превью
юнита. Клик по слоту снимает юнита с очереди и возвращает его цену
полностью, в том числе того, кто уже производится. Не помещается — ряд
тянется мышью.

## Как проверить
1. Выделить Barracks, нанять трёх Warrior — над карточками три слота,
   по первому бежит круг прогресса.
2. Первый вышел — очередь сдвинулась, круг пошёл по следующему.
3. Клик по второму слоту — он исчез, золото вернулось на 100.
4. Клик по первому, недоделанному, — прогресс сброшен, золото вернулось,
   производство перешло к следующему.
5. Еда (занято/лимит) от отмены не меняется — она занимается при
   рождении юнита.
6. Две выделенные казармы — видна очередь главной.
Клики по слотам анимированы.

## План
- [x] событие изменения очереди в `UnitProducing`, одна очередь вместо двух списков
- [x] отмена: по месту в очереди, возврат цены
  через `CommandInput.CancelProduction` → `UnitsController.CancelProduction`, как у всех кнопок
- [x] ряд слотов над карточками, круг прогресса, клик — отмена

- 2026-10-04 решения в отсутствие пользователя — Q-16, пп. 1-4: отмена без клавиши, серое вставшее производство, найм не будит вставшее производство, разрушенное здание не возвращает ресурсы.
- 2026-10-04 тест правил на возврат не писал: логика живёт в `UnitProducing` на сцене, проверено в Play mode цифрами.

## Итог
`UnitProducing` держит одну очередь (`Queue`, первый — в производстве),
событие `QueueChanged`, `Progress`, `IsStalled`, `Cancel(slot)` с полным
возвратом цены кроме еды. Ряд `HireQueue` над карточками найма: слоты на
`RingButton` с 3D-превью, `ProgressRing` золотом по ободу первого, крестик
на hover, рост и сжатие слотов при входе и выходе, драг ряда.

Проверено в Play mode: 4 юнита в очереди — золото 300000 → 299580;
отмена второго — 299680, отмена производимого — 299780, в работу пошёл
Range Unit с нуля, еда 34 без изменений. Консоль чистая.
