# T-073 · Эффекты выделенного юнита в интерфейсе

## Что нужно
Эффекты, висящие на выделенном юните (оглушение, яд, усиление), видны в
HUD — место выбрать органично. У каждого эффекта иконка: настраивается
через ScriptableObject, а если там иконки нет — берётся иконка
способности, которая наложила эффект. Для оглушения нарисовать свою
иконку. Рядом с иконкой органично — оставшаяся длительность. Зажатый ПКМ
на эффекте показывает его описание.

## Как проверить
1. `Keypad3` — оглушение выделенного: в HUD иконка оглушения со своей
   картинкой, длительность тикает, по нулю иконка уходит.
2. Гигант кастует усиление: иконка — картинка способности Rage, 10 с.
3. Зажать ПКМ на иконке эффекта — подсказка с названием и описанием.

## План
- [x] `EffectInfo` (ScriptableObject: имя, иконка, описание), поле `effectInfo` у импактов с эффектом (`IEffectImpact`)
- [x] откат к иконке способности: `SkillCatalog` — способность по ключу эффекта, наполняет `UnitSkills`
- [x] `UnitEffects.All` и `Changed`; `EffectBar` в HUD: значки, время, оправа помогает/вредит, подсказка по ПКМ
- [x] иконка оглушения `effect_stunned` + `Data/Effects/Stunned`, подключена к импакту стана `ThrowStunBolt`
- [x] проверка в Play и снимком
- [x] доки M-022, M-019


## Решения

- 2026-10-05 заведена по просьбе пользователя в чате, во время прогона
  0.3.2 (ответ в чате 2026-10-05): «Сделай еще отображение эффектов
  выбранного персонажа в этой версии где-нибудь органично».
- 2026-10-05 место — ряд левее кольца, внизу, на уровне кнопки Hold:
  рядом с полосами HP/маны выделенного, ничего не закрывает. Время —
  плашкой под значком, как клавиша под скиллом; значок темнеет по часовой.
  Оправа зелёная/красная — помогает/вредит. `EffectInfo` висит на импакте,
  а не на виде эффекта: стан от другой способности может выглядеть иначе.
  Подсказка — та же, что у скиллов (Q-22).
- 2026-10-05 по ходу: в подсказке скилла без цели (Rage, T-053) убраны
  строки «время каста 0» и «дальность 0», вид — «cast at once, no aiming».
- 2026-10-05 проверено в Play: гигант, Rage + стан 20 с + яд 75 с — три
  значка: яд (иконка Poisonous Attack, «1:11», красная оправа), стан (своя
  иконка, «16», красная), Rage (иконка способности, «6», зелёная); урон в
  кольце 39. Подсказка стана: Stunned · Effect · harms, описание из
  `EffectInfo`, Time left, From Stun Bolt. Снимок Game view — ряд левее
  кольца, ничего не перекрывает. ПКМ мышью — на приёмке.

## Итог
Эффекты выделенного юнита — ряд значков левее кольца с остатком времени, оправа помогает/вредит, подсказка по ПКМ; иконка из `EffectInfo`, иначе от способности; у стана своя иконка. Принята 2026-10-05.
