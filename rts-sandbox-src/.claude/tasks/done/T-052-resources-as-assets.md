# T-052 · Ресурсы как ассеты, а не enum в коде

## Что нужно
Новый ресурс заводится ассетом с именем, типом и иконкой, а не правкой
`ResourceName`. Задевает шесть и больше систем.

## Как проверить
Завести ассет нового ресурса — он появляется в панели ресурсов, его можно
указать в цене здания и в складе, ничего не меняя в коде.

## План
- [x] `ResourceDefinition` (ScriptableObject: имя, тип, иконка); ассеты Gold, Wood, Food в `Assets/Data/ResourceTypes/` (не `Resources/` — это особая папка Unity)
- [x] фаза 1: новые поля-ссылки рядом со старыми enum-полями, код ещё на старых
- [x] перенос данных инструментом: 13 типов юнитов, обе сцены; сверка с диска
- [x] фаза 2: код на ссылках, enum `ResourceName` и класс `Resource` удалены
- [x] проверка: компиляция, тесты, Play — цены, сдача дерева, шахта, еда, панель ресурсов
- [x] доки M-012 и соседние


## Решения

- 2026-10-04 заведена при `/plan` по концепту «Интерфейс добавление». Отложено пользователем: ответ в чате 2026-10-04, вопрос 2 интейка.
- 2026-10-05 ресурс — ассет `ResourceDefinition` (имя, тип, иконка), тип
  остался enum `ResourceType`: он про поведение (добыча, рубка, лимит), не
  про имя. Перенос в два шага с промежуточным коммитом: новые поля-ссылки
  рядом со старыми, заполнение инструментом (13 ассетов, 25 записей, обе
  сцены), сверка скриптом с исходными числами — 0 расхождений, и только
  потом удаление enum. `PlayerResources` сам заводит нулевой запас под
  новый ресурс из списка игры — иначе новый ресурс пришлось бы ещё и
  вписывать в сцену (Q-22).
- 2026-10-05 проверено: компиляция чистая, тесты 23/23. Play — шахта дала
  +80 золота, рабочие сдали +20 дерева, казарма списала 100 золота,
  родившийся воин занял 2 еды, панель «300000 / 100020 / 34/76», карточки
  найма — цены с иконками. Временный ассет «Stone» в списке игры: запас 0
  завёлся сам, трата по цене, склад принял после добавления в его список,
  в панели четвёртый пункт «20». Временный ассет удалён, сцена вернулась.

## Итог
Ресурс — ассет `ResourceDefinition` (имя, тип, иконка); enum `ResourceName` удалён, данные 13 типов юнитов и обеих сцен перенесены. Новый ресурс — ассет + строка в `GameResources`. Принята 2026-10-05.
