# T-031.3 · Все модели проекта через конвейер цвета команды

## Что нужно
Каждая модель юнита и здания проекта прошла конвейер скиллом из T-031.2:
у неё есть материал-слот `TeamColor` на командных частях. Со строгим
правилом «нет слота — не красится» это единственный способ, чтобы к выходу
0.4.0 у всех юнитов и зданий снова был цвет команды. Модели без командных
частей по замыслу (рудник, дерево) остаются без слота.

## Как проверить
Запустить игру: юниты и здания двух команд различаются цветом только на
своих командных частях, остальное у всех одинаковое. Рудник и деревья не
красятся. Ни одна модель не осталась «серой» без причины.

  WarriorCube (Warrior+Giant), MageCube, figure, Castle, farm, tower2,

  настройки подобраны по отпечатку меша в Unity (таблица в скилле)
- [x] Builder и Wall: новые FBX на месте куба

  плюс `Tools/Units/Build Placer Prefabs` — превью плейсеров (и Barracks,

## Решения

- 2026-10-05 заведена по ответу в чате на развилку при старте T-031.1:
  «строго + все модели в этой версии». Правило «модель без командных
  частей не красится» включается строго, а чтобы юниты не остались без
  цвета команды, в 0.4.0 через конвейер проходят все модели.
- 2026-10-05 ответ в чате: командные части — Warrior/Giant шипы, Caster

  кубик, Builder верхняя треть, Wall полоса по верху (как у казармы).

в `Решения`); Builder и Wall получили свои FBX-кубы. Без разметки — mine
