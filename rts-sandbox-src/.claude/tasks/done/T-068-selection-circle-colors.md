# T-068 · Цвет круга выделения по отношению к игроку

## Что нужно
Круг выделения под своим — зелёный, под врагом — красный, под нейтральным
(`IsNeutral`) или союзником, но не своим, — жёлтый. Отношение по правилам
команд и альянсов.

## Как проверить
Выделить своего, затем врага, затем юнита союзной или нейтральной команды:
круги зелёный, красный, жёлтый. Рамкой свои по-прежнему выделяются группой,
круги зелёные.

## План
- [x] три цвета — поля `GameController`, свой цвет = прежний LightGreen
- [x] `Selectable` красит круг блоком свойств по отношению к игроку при каждом выделении
- [x] проверка в Play: свой, враг, союзник/нейтральный
- [x] M-003 к факту


## Решения

- 2026-10-04 заведена при `/plan` по Q-19 (ответы в чате 2026-10-04).
- 2026-10-04 цвета — поля `GameController`, а не `Selectable`: `Selectable`

  Свой цвет — прежний `LightGreen`, красный и жёлтый выбраны ИИ (Q-22).
