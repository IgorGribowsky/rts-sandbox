# T-065.1 · Тема, иконки и панель ресурсов в новом стиле

## Что нужно
Основа нового вида: палитра, панели, кромки, шрифты и кнопки в теме,
иконки из game-icons.net (с доработкой) с лицензией. На ней — панель
ресурсов и всплывающие «+N». Остальное подтягивается следующими
подзадачами, но на новых иконках уже сейчас.

## Как проверить
1. Play. Панель ресурсов сверху — в новом стиле, числа крупные и читаются
   на светлой и тёмной земле.
2. Сдай дерево на склад — всплывающее «+N» в том же стиле.
3. Иконки в кольце и меню уже новые, без старых самодельных.
4. Лицензия набора иконок лежит рядом с иконками.

## План

- [x] Силуэты game-icons.net: выбрать, скачать в `Art/UI/game-icons/`
- [x] `make_icons.py`: обводка, тень, тон; рамки, обод, значок уровня
- [x] Лицензия рядом с иконками
- [x] Холодная палитра и акцент в теме
- [x] Панель ресурсов, «+N»
- [x] Снимок

## Решения

- 2026-10-04 решения без пользователя — Q-18 пп. 13-15: акцент —
  ледяной голубой, иконки — силуэты набора с тоном стихии, рамки плоские
  с четырьмя засечками.

## Итог

Все 20 картинок HUD перерисованы: 16 иконок из game-icons.net (Lorc,
Delapouite, Skoll, CC BY 3.0 — `Assets/UI/Icons/LICENSE-game-icons.txt`) и
4 своих (рамки, обод подсветки, значок уровня). Палитра темы холодная,
акцент — ледяной голубой. Панель ресурсов — плоская с тонкой кромкой,
иконки крупнее, числа с толстой обводкой. Проверено снимком: кольцо,
ресурсы и «+10» над замком в новом виде. Консоль чистая.

Сборка картинок: `python Art/UI/make_icons.py && python Art/UI/render.py`.
