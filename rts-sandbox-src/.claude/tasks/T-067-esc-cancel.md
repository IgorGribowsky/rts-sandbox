# T-067 · Esc отменяет текущее производство; возврат за стройку в инспекторе

## Что нужно
`Esc` при выделенном производящем здании отменяет юнита, который
производится сейчас, с полным возвратом цены, — следующий в очереди
начинает производиться. Выделено несколько зданий — каждое отменяет своего
текущего. Процент возврата при отмене стройки — поле на `GameController`,
по умолчанию 70% (сейчас константа `GameConstants`).

## Как проверить
1. Казарма, поставить в очередь трёх воинов, нажать `Esc`: первый пропал,
   золото и еда вернулись полностью, производится следующий.
2. Начать стройку фермы, `Esc` по недостроенной: вернулось 70%.
3. В инспекторе `GameController` поставить возврат 50%, повторить п. 2:
   вернулась половина.

## План
- [x] `UnitProducing` слушает `Canceled` и снимает текущего (слот 0)
- [x] процент возврата стройки — поле `GameController`, константа уходит
- [x] доки M-010, M-011, M-001 — к факту
- [x] компиляция, консоль, проверка в Play


## Решения

- 2026-10-04 заведена при `/plan` по Q-19 (ответы в чате 2026-10-04).
- 2026-10-04 `Esc` по готовому зданию идёт тем же событием `Canceled`, что
  и отмена стройки: `UnitProducing` выключен, пока здание строится, так что
  две отмены не пересекаются. Процент — целое 0..100 в инспекторе, не доля
  (Q-22).
- 2026-10-04 проверено в Play: очередь из трёх, `Esc` — первый ушёл, 100
  золота вернулось, в работе второй; ферма (80 золота) при 70% вернула 56,
  при 50% — 40.
