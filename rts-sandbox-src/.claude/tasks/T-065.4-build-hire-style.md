# T-065.4 · Меню построек и найма в новом стиле

## Что нужно
Кнопка стройки, карточки построек, список найма, очередь найма и их
подсказки — в новом стиле. Поведение не меняется.

## Как проверить
1. Play. Выдели рабочего, открой меню построек — карточки в новом стиле,
   цена и недоступность читаются сразу.
2. Выдели казарму, найми 3 юнитов — список и очередь в новом стиле,
   прогресс виден, отмена работает.
3. Подсказки по ПКМ на карточках — в новом стиле.

## План

- [x] Карточки: плоская тёмная панель, светлая кромка сверху, превью в рамке
- [x] Наведение — кромка акцентом, метка клавиши — без акцента
- [x] Снимки: меню построек у рабочего, очередь найма у казармы
- [x] Панели непрозрачные — линейный цвет делал их серыми

## Решения

- 2026-10-04 метка клавиши на карточке больше не акцентная: клавиша — не
  «происходит сейчас». Акцентом остаётся наведение, открытое меню (свечение
  кнопки стройки) и прогресс найма.
- По ходу: панели HUD стали непрозрачными (`--color-panel` без альфы,
  `--color-panel-sunken` 0.98). Проект в линейном цвете — 3% просвета
  белой земли давали серый вместо тёмного. Запись в `ui-style.md`.

## Итог

Кнопка стройки, карточки построек и найма, очередь найма — в новом стиле:
плоские тёмные карточки со светлой верхней кромкой, превью в тёмной рамке,
клавиша — тёмная плашка, наведение подсвечивает кромку ледяным голубым,
кнопка стройки при открытом меню светится, слоты очереди — круглые рамки с
засечками и голубым кольцом прогресса. Проверено снимками: меню построек у
Builder, очередь из 4 юнитов у Barracks. Консоль чистая.

Глазами: подсказки по ПКМ на карточках, отмена в очереди, недоступная по
цене карточка.

Файлы: `Hud.uss`, `theme.uss`.
