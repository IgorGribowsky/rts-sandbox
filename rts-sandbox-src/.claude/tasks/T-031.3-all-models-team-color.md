# T-031.3 · Все модели проекта через конвейер цвета команды

## Что нужно
Каждая модель юнита и здания проекта прошла конвейер скиллом из T-031.2:
у неё есть материал-слот `TeamColor` на командных частях. Со строгим
правилом «нет слота — не красится» это единственный способ, чтобы к выходу
0.4.0 у всех юнитов и зданий снова был цвет команды. Модели без командных
частей по замыслу (рудник, дерево) остаются без слота.

## Как проверить
Запустить игру: юниты и здания двух команд различаются цветом только на
своих командных частях, остальное у всех одинаковое. Рудник и деревья не
красятся. Ни одна модель не осталась «серой» без причины.

  цвета команды, в 0.4.0 через конвейер проходят все модели.
