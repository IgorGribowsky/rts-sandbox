# T-050 · Список найма у производящего здания

## Что нужно
Выделено здание, которое производит, — слева снизу всегда виден ряд
карточек юнитов с превью и ценой, без кнопки открытия. Клик по карточке —
то же, что цифра: юнит встаёт в очередь. Выделено несколько одинаковых
зданий — приказ всем. Подсказка по зажатому ПКМ, прокрутка драгом.

## Как проверить
1. Выделить Barracks — видны карточки Warrior и Range Unit. Выделить Farm
   — карточек нет.
2. Клик по Warrior — золото списано, над казармой пошла полоска
   производства. Клавиша `2` — встал Range Unit.
3. Выделить две казармы, клик — производство в обеих.
4. Зажать ПКМ на карточке — подсказка с ценой, временем, здоровьем,
   атакой.

Клики анимированы.
