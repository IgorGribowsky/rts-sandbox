# T-031.1 · Захваченный рудник: балки в цвет команды

## Что нужно
Первый проход конвейера (`docs/08-model-pipeline.md`): Blender MCP
подключён, модель захваченного рудника размечена — балки получили
командный слот, при необходимости меш порезан, экспорт в проект. В Unity
красятся только командные слоты; модель без них не красится вообще.

## Как проверить
Захваченные рудники двух команд рядом: сам рудник одинаковый, балки — цвета
своей команды. Обычный рудник и прочие заглушки без разметки не красятся.
