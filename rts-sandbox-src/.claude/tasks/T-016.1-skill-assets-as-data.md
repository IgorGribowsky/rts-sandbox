# T-016.1 · Ассет способности — чистые данные, исполнение в обычных классах

## Что нужно
Первая из трёх подзадач T-016. Закрывает требования 1 и 2 из M-015.

Сейчас `SkillAction` — это `ScriptableObject` с методом `Act()`: ассет и
исполняемый код одно и то же. Надо развести. Ассет описывает «что за
способность» — числа, ссылки на префабы, набор импактов. Исполнитель —
обычный класс, который эти данные читает.

Схема та же, что уже принята для поведений в T-021: тип в enum, один
явный factory-switch, класс-исполнитель рядом. Новая способность — это
новый ассет; новый ВИД способности — новый класс плюс строка в фабрике.

Затрагивается: `Abstract/SkillAction.cs`, `ActiveSkillAction`,
`CastToPointAction`, `PassiveSkillAction`, три класса в `SkillActions/`,
`SkillImpact` и два импакта, `SkillParams`, вызов `Action.Act` в
`UnitSkills.Cast`.

## Как проверить
Кастер применяет все три способности: Light Orb, Water Wave, Blink.
Урон, дальность, скорость снаряда и дальность телепорта — прежние.

## Решения

- 2026-09-06 (ответ в чате) T-016 разбита на три подзадачи, это первая.
- Числа существующих ассетов сняты с диска ДО работы и должны совпасть
  после пересборки:

  | Ассет | Значения |
  |---|---|
  | ThrowLightOrb | speed 20, range 13, target Enemies, impact InstantDamage 60 Magic |
  | ThrowWaterWave | speed 13, range 10, width 2.4, target Enemies, impact InstantDamage 40 Magic |
  | Blink | MaxRange 8, импактов нет |
  | LightOrb | cd 3.5, cast 0.15, range 12.5, mana 25 |
  | WaterWave | cd 7, cast 0.2, range 9.5, mana 55 |
  | Blink | cd 3, cast 0.15, range 50, mana 30 |

  Импакты лежат в `[SerializeReference]`, при смене формы классов они
  теряются молча — пересобирать и читать обратно с диска.
