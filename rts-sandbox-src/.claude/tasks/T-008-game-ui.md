# T-008 · Ресурсы на экране — каркас интерфейса и тема

## Что нужно
Появляется интерфейс на UI Toolkit в стиле `references/menu.jpg`: наверху,
правее места под миникарту, — ресурсы с иконками. Список берётся из
`GameResources`, иконка — поле там же, еда показывается как «занято/лимит».
Цвета и размеры — переменные темы, на них дальше стоит весь интерфейс
версии. Иконки ресурсов сгенерированы.

## Как проверить
1. Запустить сцену: наверху золото `300000`, дерево `100000`, еда `0/10`,
   каждое со своей иконкой.
2. Нанять строителя в Castle — золото минус 60, еда `1/10` сразу.
3. Нарубить дерево и сдать на склад — число дерева растёт.
4. Построить Farm — после достройки лимит `16`.
5. Поменять размер окна Game — панель не уезжает за край и не
   растягивается уродливо.
6. Стиль — глазами: один стиль с референсом, не «нейрослоп».
