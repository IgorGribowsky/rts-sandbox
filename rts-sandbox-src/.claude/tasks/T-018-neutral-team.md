# T-018 · Правила союзничества: IsNeutral и команда без альянса

## Что нужно
Спека (ответ в чате 2026-09-05):

1. **Всё, что работает сейчас, работает так же.** Обычные команды с
   альянсами поведения не меняют.
2. **`Team.IsNeutral` начинает работать:** такая команда считается
   союзником **всем**, вообще не глядя на команды и альянсы. Её не
   атакуют, и она не атакует.
3. **Команда без альянса считается как будто она одна в своём альянсе:**
   союзник только самой себе, враг всем — кроме команд с `IsNeutral`.

Сейчас правило 3 работает иначе: `GetAllyTeams(id)` возвращает
объединение альянсов, куда входит команда. Команда, не входящая ни в один
альянс, получает **пустой** список союзников — включая саму себя, — и
дальше `GetEnemyTeams` записывает её во враги себе. Флаг `IsNeutral` при
этом объявлен и не читается нигде.

Правки все в `TeamController`: `GetAllyTeams` и `GetEnemyTeams`.

**Две разные сущности, не противоречие.** Мирные нейтралы — `IsNeutral`,
союзники всем. Агрессивные нейтралы («против всех») — обычная команда
**без альянса**. В коде их надо звать по-разному.

## Как проверить
Три случая рядом друг с другом, юниты вплотную:

- два юнита команды 99 (`IsNeutral`) и юнит игрока — никто ни с кем не
  дерётся;
- юниты команды без альянса и юнит игрока — дерутся;
- те же юниты без альянса и юнит команды 99 — не дерутся;
- две обычные команды в разных альянсах — дерутся, как и раньше.

## План

1. Сначала снять «как есть» — таблицу союзников и врагов по всем
   четырём командам сцены.
2. Переписать `GetAllyTeams` и `GetEnemyTeams` по спеке, назвав мирную
   команду отдельным словом (`IsPeaceful`), чтобы её не путали с
   «против всех».
3. Снять ту же таблицу после и сверить с правилами.
4. Проверить боем все три случая на живых юнитах, на навмеше.
5. Решить, что делать с побочным эффектом ПКМ по мирному.

## Ход работы

- 2026-09-11 **снято «как есть»** (сцена: команды 1, 2, 3 и 99, альянсы
  `{1,2}`, `{3}`, `{99}`, у 99 стоит `IsNeutral`):

  | Команда | Союзники | Враги |
  |---|---|---|
  | 1 | 1, 2 | 3, 99 |
  | 2 | 1, 2 | 3, 99 |
  | 3 | 3 | 1, 2, 99 |
  | 99 (`IsNeutral`) | 99 | 1, 2, 3 |

  То есть флаг действительно мёртв: мирная команда воюет со всеми.
- 2026-09-11 `TeamController` переписан: появился `IsPeaceful(id)`,
  `GetAllyTeams` добавляет саму команду и все мирные команды,
  `GetEnemyTeams` у мирной команды возвращает пустой список. Кеш из
  T-011 сохранён, сбрасывается `InvalidateTeamCache`.
- 2026-09-11 M-009 переписан под новые правила, включая таблицу и
  оговорку про два разных «нейтральных».

### Проверка фактами

**Таблица после правки** — ровно по спеке:

| Команда | Союзники | Враги | Правило |
|---|---|---|---|
| 1 | 1, 2, 99 | 3 | 1 и 2 |
| 2 | 1, 2, 99 | 3 | 1 и 2 |
| 3 | 3, 99 | 1, 2 | 1 и 2 |
| 99 (мирная) | 1, 2, 3, 99 | — | 2 |

**Команда без альянса.** В сцене такого случая нет, поэтому он собран в
Play mode: у команды 3 отобран её альянс `{3}`. Результат не изменился ни
на строку — союзники `{3, 99}`, враги `{1, 2}`, — то есть команда без
альянса теперь ведёт себя как одна в своём альянсе, а не как враг себе.

**Бой.** Семь воинов расставлены на навмеше тремя группами по 2.5 метра
друг от друга, 16 секунд без вмешательства:

| Случай | Результат |
|---|---|
| два мирных (99) + юнит игрока | все трое 140/140, никто никого не тронул |
| команда без альянса (3) + юнит игрока | **оба убиты** — дерутся |
| команда без альянса (3) + мирный (99) | оба 140/140 — не дерутся |
| две обычные команды в разных альянсах | дерутся, проверено на сцене в T-013: у команды 3 было 66 юнитов и 28180 HP, стало 63 и 27457 |

- Консоль пустая.
- Побочный эффект проверен на живых объектах: ПКМ по мирному юниту даёт
  `FollowingBehaviour`, `A`-клик по нему же — `MeleeAttackingBehaviour`.
  То есть ударить мирного по-прежнему можно, просто намеренно.

## Решения

- 2026-09-05 найдено при `/adopt` чтением кода: команда без альянса враг
  сама себе.
- 2026-09-05 (ответ в чате) «против всех» — норма. Задача сузилась до
  нейтралов между собой, заведён Q-8.
- 2026-09-05 (ответ в чате) полная спека союзничества, Q-8 закрыт.
- 2026-09-05 (ответ в чате) две сущности: `IsNeutral` — мирные, команда
  без альянса — агрессивные против всех.
- 2026-09-11 (решено ИИ) **побочный эффект с ПКМ принят.** По мирному
  юниту теперь Follow, а не атака. Атака осталась на `A`-клике — это
  обычное поведение RTS по отношению к нейтралам. Для шахт не меняется
  вообще ничего: они неуязвимы, и ПКМ по ним раньше запускал заведомо
  бесполезную атаку. **Если хочется, чтобы ПКМ по мирному был атакой,
  скажи — это одна проверка в `OnUnitRightClick`.**
- 2026-09-11 (решено ИИ) **поле `IsNeutral` не переименовано.** Имя
  сериализовано в сцене, переименование обнулило бы флаг у команды 99
  молча. Вместо этого заведён метод `IsPeaceful(id)` и подсказка в
  инспекторе, а разница между «мирный» и «против всех» расписана в
  M-009.
- 2026-09-11 (решено ИИ) **случай «команда без альянса» проверен в Play
  mode, а не правкой сцены.** В сцене такой команды нет; заводить её ради
  проверки значило бы менять расстановку, которую пользователь собирал
  сам.
- 2026-10-04 (ответ в чате, Q-11) ПКМ по мирному юниту = Follow
  **подтверждено**.

## Итог

Флаг `IsNeutral` перестал быть мёртвым: команда 99 — союзник всем и враг
никому, её юниты и шахты в бою не участвуют. Команда без альянса больше не
враг сама себе: она союзник себе и мирным, враг остальным. Обычные команды
1, 2 и 3 воюют ровно как раньше.

Что осталось на глаз пользователя: устраивает ли Follow по ПКМ на мирном
юните.
