# T-072.5 · Механика из игры уходит в движок: воскрешение

## Что нужно
Пример из концепта: в игре просят способность «воскрешает существо при
смерти, кулдаун 300 с». Механики нет в движке — ИИ добавляет её в пакет,
а способность-ассет — в игру. Новая версия движка с заметками; игра
переходит на тег.

## Как проверить
В игре: юнит со способностью умирает — воскресает, повтор раньше 300 с не
срабатывает. В rts-sandbox механика доступна для любого юнита. В журнале
движка — новая версия с пометкой «не ломает».
