# T-014 · Снаряд разворачивается по неверной точке

## Что нужно
`ProjectileBehavior.Update` делает `transform.LookAt(moveVector)`, где
`moveVector` — это вектор смещения за кадр, а `LookAt` ждёт мировую точку.
В итоге снаряд смотрит не по направлению полёта, а в точку рядом с началом
координат. Правильно — `LookAt(transform.position + moveVector)` или
`rotation = Quaternion.LookRotation(moveVector)`.

Заодно проверить два соседних места:

- снаряд не имеет времени жизни: при живой, но недостижимой цели летит
  бесконечно;
- `ThrownProjectile` (снаряды способностей) разворачивается один раз при
  запуске и дальше летит прямо — там ошибки нет.

## Как проверить
Стрелком выстрелить по цели сбоку и сверху: снаряд `Bullet` летит носом
вперёд на всём пути.
