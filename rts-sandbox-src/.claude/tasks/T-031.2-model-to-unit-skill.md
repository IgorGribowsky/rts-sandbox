# T-031.2 · Скилл «любая модель → юнит с цветом команды»

## Что нужно
Конвейер из T-031.1 оформлен скиллом: по просьбе в чате ИИ берёт модель,
предлагает командные части, размечает (режет меш, если нужно), экспортирует
и подключает в тип юнита. Проверка на второй модели, не руднике.

## Как проверить
Попросить в чате: «сделай казарму с командными частями». ИИ показывает,
какие части пойдут в цвет команды, после подтверждения казармы двух команд
в сцене отличаются только этими частями.
