# T-055 · Очередь найма на экране с отменой

## Что нужно
Над карточками найма — ряд слотов очереди выделенного здания: первый с
круговым прогрессом производства, за ним ожидающие, у каждого 3D-превью
юнита. Клик по слоту снимает юнита с очереди и возвращает его цену
полностью, в том числе того, кто уже производится. Не помещается — ряд
тянется мышью.

## Как проверить
1. Выделить Barracks, нанять трёх Warrior — над карточками три слота,
   по первому бежит круг прогресса.
2. Первый вышел — очередь сдвинулась, круг пошёл по следующему.
3. Клик по второму слоту — он исчез, золото вернулось на 100.
4. Клик по первому, недоделанному, — прогресс сброшен, золото вернулось,
   производство перешло к следующему.
5. Еда (занято/лимит) от отмены не меняется — она занимается при
   рождении юнита.
6. Две выделенные казармы — видна очередь главной.
Клики по слотам анимированы.
