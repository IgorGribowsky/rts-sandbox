# T-056 · Всплывающие числа при поступлении ресурса

## Что нужно
Ресурс пришёл в казну — над местом, где это случилось, всплывает «+N» с
иконкой ресурса, поднимается и тает: над складом при сдаче дерева, над
шахтой при выдаче порции золота. На каждый удар по дереву числа нет.

## Как проверить
1. Рабочий сдаёт дерево на Castle — над замком «+10» с иконкой дерева,
   поднимается и исчезает; число дерева наверху выросло на столько же.
2. Пятеро в шахте — над шахтой каждую секунду «+10» с иконкой золота.
3. Отвести камеру от шахты — чисел на краю экрана не висит.
4. Двадцать рабочих разом — числа не сливаются в кашу, FPS не падает.

## План
- [x] событие «ресурс получен в точке» из сдачи на склад и выдачи шахты
  заодно склад сдаёт через `AddResource`: раньше счётчик дерева наверху не менялся
- [x] всплывающая метка UI Toolkit, привязанная к точке мира, пул меток
- [x] стиль, анимация подъёма и таяния

## Решения

- 2026-10-04 заведена при `/plan` по концепту «интрерфейс». Когда всплывает — ответ в чате 2026-10-04, вопрос 3, вариант A.

- 2026-10-04 решения в отсутствие пользователя — Q-16, пп. 5-7: зелёный цвет чисел, слияние одинакового дохода, починка счётчика дерева.

## Итог
Событие `PlayerEventController.ResourceGained` (ресурс, сколько, точка) из
`HarvestedResourcesStorage.Store` и `HeldMine`. `ResourcePopups` в HUD: пул
из 24 меток в слое под панелями, привязка к точке мира через
`RuntimePanelUtils.CameraTransformWorldToPanel`, вспышка, подъём на 70 px и
таяние за 1.3 с, тик только пока есть живые метки. Одинаковый доход в том
же месте за 0.35 с складывается.

Проверено в Play mode: сдача 10 дерева на Castle — дерево 100000 → 100010,
над замком «+10» с иконкой; двадцать сдач подряд — одно «+200», дерево
+200. Консоль чистая.
